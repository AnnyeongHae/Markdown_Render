# [구현 계획서] 다이어그램 글자 깨짐 방지 및 인터랙티브 팝업 뷰어 고도화

사용자분의 비판적 피드백(글자 찌그러짐, 레이아웃 공간 협소, 가독성 저하)을 해결하기 위한 **SVG 폰트 크기 보정 및 85% 모달 팝업 뷰어 구현 전략**입니다.

---

## 🔍 비판적 원인 분석 (왜 글자가 작아지고 깨졌는가?)

1. **SVG viewBox 비율에 의한 전체 극단 축소**:
   - `flowchart LR`처럼 옆으로 길거나 수직으로 긴 다이어그램을 카드 너비(약 750px)에 맞춰 `width: 100%`로 강제 축소하다 보니, 전체 폰트 크기가 2~4px 수준으로 줄어들어 글자가 찌그러졌습니다.
2. **Mermaid HTML Label 폰트 계산 불일치**:
   - Mermaid가 렌더링할 때 사용된 폰트 크기와 CSS 가상 폰트 크기가 일치하지 않아 박스를 삐져나오거나 글자가 깨졌습니다.

---

## 🛠️ 해결 방안 (사용자 제안 반영)

### 1. 기본 카드 영역: 깔끔한 가독성 보장 (`14px` 폰트 고정)
- 기본 카드 내에서는 SVG의 폰트 크기를 `14px`로 고정하고 최소 너비/높이를 확보하여 **글자가 찌그러지거나 잘리지 않도록 정돈**합니다.
- 카드 상단에 **`🔍 크게 보기 (클릭)`** 안내 툴바 버튼을 제공합니다.

### 2. 클릭 시 85% 팝업 뷰어 (Iframe/Modal 방식)
- 전체 화면을 답답하게 덮지 않고, 화면의 85% 크기(`85vw`, `85vh`)로 **여유로운 다이어그램 전용 팝업 뷰어**를 띄웁니다.
- 팝업 클릭 또는 다이어그램 클릭 시 바로 팝업으로 크게 확대됩니다.

### 3. 팝업 뷰어 내 자유 인터랙션 (Pan, Zoom, Scroll)
- 팝업 안에서 마우스 휠(Wheel Zoom), 줌 버튼(`＋`, `－`, `100%`), 마우스 드래그(Pan)를 통해 원하는 글자와 구성을 100% 선명하게 확인 가능합니다.

### 4. 기존 PNG / SVG 다운로드 유지
- 팝업 상단 툴바에서 SVG 및 고화질 PNG 저장 버튼 제공.

# Walkthrough - PDF/HTML 벡터 SVG 유지 & Word용 3x Retina PNG 하이브리드 완수

질문하신 **"PDF/HTML 내보내기 시 깨짐 없는 SVG 포맷 적용 가능 여부 및 Word의 SVG 호환성"**에 대한 기술 검증 및 **하이브리드 내보내기 전략(Hybrid Export Strategy)** 고도화를 완료했습니다.

---

## 📊 내보내기 포맷별 최종 기술 구현 결과

| 내보내기 형식 | 적용 포맷 | 구현 방식 및 화질 |
| :--- | :--- | :--- |
| **PDF 저장 (`exportPdf`)** | **원본 벡터 SVG (`SVG`)** | **PNG 변환 과정을 제거하고 원본 벡터 SVG 그대로 인쇄** ➔ PDF 문서 확대 시 다이어그램의 글자와 선이 **1px도 안 깨지는 100% 최상급 벡터 PDF** 생성 |
| **HTML 저장 (`exportHtml`)** | **원본 벡터 SVG (`SVG`)** | **인라인 벡터 SVG 형태 그대로 저장** ➔ 브라우저에서 무한 확대해도 쨍한 벡터 화질 보존 |
| **Word 저장 (`exportDocx`)** | **3x Retina PNG (300 DPI 레벨)** | 구형 Word / 한글(HWP) 등에서 HTML 기반 SVG 로드 시 발생하는 **엑스박스(X-Mark) 버그 방지** ➔ **2400px급 3x Retina PNG로 업스케일 인코딩**하여 엑스박스 없이 쨍하게 삽입 |

---

## 🛠️ 완수된 핵심 변경 사항

1. **PDF 및 HTML 내보내기**:
   - 다이어그램을 PNG로 바꾸는 단계를 건너뛰고 **원본 SVG 노드를 100% 직접 전달**합니다.
   - 브라우저 인쇄 엔진과 HTML 렌더러가 벡터 그래픽으로 직접 그리므로 깨짐 현상이 완전히 사라집니다.

2. **Word(.docx) 내보내기**:
   - MS Word 호환성 유지를 위해 PNG를 사용하되, 기존 캔버스 해상도 대비 **3배(Retina 300 DPI 급)**로 인코딩 해상도를 대폭 상향했습니다.

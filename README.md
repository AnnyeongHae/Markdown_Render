## 🇺🇸 English

### ✨ Key Features
- **Mermaid Live Renderer & 85% Modal Viewer**: Real-time rendering for ```mermaid ``` code blocks and `.mmd` diagram files. Click any diagram to open an 85% full-screen modal with mouse wheel zoom, pan dragging, and SVG/PNG exports.
- **Multi-Format Document Conversion**: Export Markdown documents to PDF (print page-break avoidance), MS Word `.docx` (A4 scale fit), HTML, and PNG.
- **ASCII & Box Drawing Alignment**: Auto-detects text architecture boxes (`┌─┬─┐`, `│...│`) and applies monospace fonts to prevent line breaking.
- **Local Folder & Zip Ingestion**: Drop entire folders with Markdown files and relative image assets. Blobs are resolved 100% locally with ZERO server uploads.

👉 **[Try Live Demo Website](https://markdownrender.pages.dev/)**
